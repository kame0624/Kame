              アクセス解析(GoatCounter)

              広告や個人情報の収集がない、無料のアクセス解析です(個人利用向け)。
              1. goatcounter.com で登録して、好きな「コード」を決める → 2. 下に入れて「サイトの計測を有効にする」 → 3. 数字を見たいときは、GoatCounterの User → API でトークンを作って入れる。

              ダッシュボードを開く

              数字を見る

              ブラウザから読めないときは、「ダッシュボードを開く」から見てください(GoatCounter側の制限で、ここに出せない場合があります)。

              設定

              パスワードでトークンを暗号化して、この端末に保存します。管理ページを開くたびにパスワードが必要で、15分操作しないと自動でロックされます。

              トークンはこの端末のブラウザ内にだけ保存され、GitHub以外には送られません。
              作り方: GitHub → Settings → Developer settings → Fine-grained tokens → Generate。 Repository access は Kame だけ、Permissions の Contents を Read and write にしてください。

              アプリとして使う

              ボタンが出ないとき:
              Android(Chrome) … 右上のメニュー(︙)→「ホーム画面に追加」または「アプリをインストール」
              iPhone(Safari) … 下の共有ボタン→「ホーム画面に追加」
